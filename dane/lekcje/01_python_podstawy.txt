# Python — podstawy

Python to język programowania. Python został stworzony przez Guido van Rossuma. Język programowania to sposób zapisu instrukcji dla komputera. Program to ciąg instrukcji wykonywanych przez komputer. Zmienna to pojemnik na dane w programie. Zmienna ma nazwę i wartość. Liczba całkowita to typ int. Liczba ułamkowa to typ float. Tekst to typ str. Wartość logiczna to typ bool. Komentarz to tekst pomijany przez interpreter. Komentarz zaczyna się od znaku krzyżyka. Wcięcia określają bloki kodu w Pythonie. Funkcja print wypisuje tekst na ekran. Funkcja input pobiera tekst od użytkownika. Operator przypisania zapisuje wartość do zmiennej. Interpreter to program wykonujący kod Pythona. Błąd składni to błąd w zapisie programu. Debugowanie to szukanie i poprawianie błędów w programie.
